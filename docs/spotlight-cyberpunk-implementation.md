# Spotlight cyberpunk visual pass

Spotlight-only visual pass over the already-approved layout. Files: `spotlight-discovery.mjs`, `spotlight-discovery.css`, `spotlight.css`, `spotlight.html`. Nothing shared changed — `index.html`, `style.css`, `app.js`, the catalogue, player, assets and tests are untouched, and no package, backend or motion feature was added.

Background: `html.page-spotlight` drops `--bg` to `#0b0d0b`; body inherits it, the header is `#0b0d0bfa`, and the hero's bottom fade now ends on `#0b0d0b` so the hero, header and footer meet without a seam. Header and footer wordmarks are now the `assets/gameflex-curve.svg` image (alt `GAMEFLEX`, anchor keeps `class="wordmark"` and its "GAMEFLEX home" name): ~158x32 in the header, ~180x36 in the footer, 140x28 on phones. The 75px desktop header is unchanged.

Shelf headings replace the sparkle with thirteen original stroke-only glyphs (24 viewBox, fill none, 1.7px stroke, drawn at 22x22, each tagged `data-sd-glyph` so QA can see the shuffle). They are shuffled once per init and stored in a `Map` keyed by `row.id`, so a shelf keeps its mark across filters, favourites, re-renders and repaints, and the eleven rows of a default browse never repeat one. The glyph and the title text sit in two fixed grid columns; the title text is wrapped in `.sd-title-text` and the subtitle pads to the same gutter, so it aligns with the text, not the glyph. Top games now uses the same warm-white title and muted count/subtitle as every other shelf — the old all-lime heading override is gone.

Top games follows the Netflix reference: each card is a two-column grid — oversized dark numeral (fill `#0b0d0b`, 2px `#717570` stroke, no glow) behind a 2:3 poster on the right, in an ~47/53 split. The numeral is sized in card-relative `cqw` (not `vw`) off the poster height; `line-height:.9` keeps its box taller than the poster and a small negative bottom margin lands the baseline on the poster's bottom edge. Rank 10 is the two-digit case: `fs:100cqw` sizes the full pair to one digit's em and `scaleX(.4)` with `transform-origin:left bottom` compresses that pair horizontally, keeping the poster height and landing both digits in the 47% rank region. Six ranked cards still fit at desktop; phones hold two per row so the posters never thin out.

Continue playing loses the Preview badge and its CSS copy entirely. The fresh-browser preview is five games with the plain subtitle "Start a game to begin your history."; real history still supersedes it and still stores up to 20 ids. The demo/recent row fits five wider cards at desktop and steps 5 → 4 → 3 → 2; every other row keeps six at desktop. `data-sd-shelf="demo"`/`"recent"` remain as QA hooks, all 54 curated ids still appear, and the hover panel (300px), titles under artwork, autoplay, keyboard, touch and sandbox gates are unchanged.

Nav keeps the explicit green underline — 2px, 24px wide, centred under the label at `bottom:3px` inside the button, identical on desktop and mobile, no pill and no header-height change.

Verification: `node --check dist/spotlight-discovery.mjs` and `npm run check` both pass. No browser screenshots or runtime QA were run here; gameplay, embedding permission and visual regressions are not established by these checks.
